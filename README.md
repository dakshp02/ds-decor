# DS Decor E-commerce Website

Milestone 1 creates the project structure, homepage layout, Firebase connection files, and the first Firestore product fetch.

## Current Scope

- Responsive homepage
- Responsive navbar
- Hero section
- Shop by category section
- First product loaded from Firestore
- Footer
- Placeholder pages for future milestones

## Local Testing

Run a local server from this folder:

```powershell
python -m http.server 5500
```

Then open:

```text
http://127.0.0.1:5500/
```

Do not open `index.html` directly, because ES module imports work best through a local server.
